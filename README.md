# VPN & REMOTE ACCESS SECURITY AUDIT TOOL

## Overview
This project is designed to automate network scanning and vulnerability assessment using Bash scripting and Nmap within a Ubuntu environment.The tool performs service detection, open port identification, and vulnerability scanning on selected targets. 

## Features
- Service detection
- vulnerability scanning
- Automated script execution

## Technologies Used
- Bash Scripting
- Nmap
- NSE
- Ubuntu/WSL Environment

## How to Run
- Open terminal and navigate to the project directory:
cd vpn-audit-tool
- Run the scanning script:
bash scan.sh
- Enter the target domain when prompted.

## Output
- scan-$DATE.txt
- vuln_$DATE.txt
- report.md
- README.md

## Disclaimer
This tool should only be used on authorized systems.
